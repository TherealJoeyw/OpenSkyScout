# Extended Narrations

This folder contains additional audio narrations that were not included with the original Celestron SkyScout.

These narrations were generated using an AI voice clone of the original SkyScout narrator created with ElevenLabs. The scripts were also generated with AI assistance.

These narrations have not been verified and may contain factual errors, omissions, or outdated information.

They should be treated as an unofficial enhancement to the project rather than an authoritative source of astronomical information. Please verify any important facts using reliable astronomical references.
